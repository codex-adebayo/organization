# Professional portfolio direction

FORME is presented as an independent digital practice across automation, web design,
and cybersecurity. The experience uses an original graphite, ivory, acid-green and
warm-gold system. The still convergence sculpture represents the three practices
meeting in one delivery partner.

## Narrative

The page moves through a clear sequence:

1. A single promise: build better and move securely.
2. Three practice chapters that show inputs, delivery stages, human checkpoints,
   and concrete outputs.
3. Three self-initiated concept studies that demonstrate the agency's thinking
   without claiming clients or results.
4. A shared operating model and delivery standards.
5. A browser-only project brief covering all three practices.

BugBunny informed the narrative discipline: a direct promise, operational examples,
visible human judgment, and a decisive invitation. No visual assets, copy, brand
elements, code, metrics, customer claims, or interface layouts were copied.

## Motion

Jakub leads the production polish, Jhey informs the bolder editorial composition,
and Emil governs navigation and form feedback. The existing Effects contract remains
authoritative. Hero copy enters once; lower sections reveal independently; only the
three practice chapters and four process steps use progression offsets. The sculpture
and atmosphere remain still. Reduced motion exposes every final state immediately.

## Content status

SignalOS, Northstar, and Gatehouse are self-initiated concepts. Their dialogs state
that no customer deployment or measured result is claimed. Service descriptions are
capability statements and proposed outputs. The project form creates a local text
download and does not transmit personal information.

## Verification

GitHub Actions runs source checks, the Effects contract, the retained Kino document
validator, a Next.js production build, and Playwright on desktop and mobile Chromium.
Tests cover all practices, concept qualification, keyboard dialog behavior, downloaded
briefs, reduced motion, no-JavaScript reading, responsive overflow, WebGL fallback, and
metadata. Automated browser checks do not establish real-device performance or a
manual visual approval.
